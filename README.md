# PlayBax App (Android)

Live delayed video playback (`1s–30s` interval) for sports, fitness, and physical-activity self-coaching with 1 to 3 cascading delayed screens (`+1×`, `+2×`, `+3×` delay) in Portrait Stacked or Landscape Side-by-Side layouts, memory-only ring buffering, and optional MP4 gallery recording.
